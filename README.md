## Run the complete application

### 1. Frontend
Open a terminal in `frontend`:

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal, normally `http://localhost:5173`.

### 2. Optional FastAPI backend
Open another terminal in `backend`:

```bash
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload --port 8000
```

API health: `http://127.0.0.1:8000/api/health`

The frontend is designed to remain fully usable for the SIH presentation even if the optional API is not running; the UI uses connected local application state for the presentation workflows.

## Important

`node_modules` is intentionally not packaged because it is generated by npm for the specific Windows/Node environment. Running `npm install` creates it automatically from the included `package.json`. No source-code editing is required.


## Authentication
